# Phishing Risk ML Platform

An end-to-end machine learning project for detecting and explaining phishing risks.

## Project Status

Work in progress. The project is currently in the data exploration and baseline modelling stage.

## Problem

Phishing attacks use deceptive messages, URLs and websites to steal sensitive information. This project aims to build a machine learning system that identifies potential phishing attempts and explains the factors influencing its predictions.

## Planned Features

- Data cleaning and exploratory analysis
- Feature engineering
- Baseline and ensemble machine learning models
- Model comparison and evaluation
- Explainable AI
- FastAPI prediction service
- Automated testing
- Docker deployment
- Responsible AI and security analysis

## Planned Technologies

- Python
- pandas and NumPy
- scikit-learn
- XGBoost
- SHAP
- FastAPI
- pytest
- Docker
- GitHub Actions

## Repository Structure

The repository structure will be added as the project develops.

## Evaluation

The project will evaluate models using precision, recall, F1-score, ROC-AUC and confusion matrices. Accuracy alone will not be used because phishing datasets may contain class imbalance.

## Responsible AI

The system will be treated as a decision-support tool rather than a replacement for human cybersecurity judgment. False positives, false negatives, data privacy, model drift and adversarial manipulation will be considered.
